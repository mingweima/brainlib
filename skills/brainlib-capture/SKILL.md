# 记录和查找

## 什么时候记

按用户第 5 题的选择（`brainlib onboard summary` 里的 `record_policy`）：

| 设置 | 记什么 |
|---|---|
| explicit_only | 只在用户说“记住”“记一下”的时候记 |
| important（默认） | 用户说出的偏好、决定、关于他自己的事实 |
| with_inferences | 再加你的观察，必须用 `--inferred` |
| with_external | 再加外部资料，必须用 `--external 来源` |

brainlib 会按这个设置拦住不该记的类型（退出码 4）。被拦了就不记，不要换个标签硬记。

## 怎么记

`brainlib note "<内容>" <来源标签>`

| 情况 | 标签 | 例子 |
|---|---|---|
| 用户的原话 | `--said` | `brainlib note "我早上只喝茶，不喝咖啡" --said` |
| 用户明确的看法（你转述的） | `--judgment` | `brainlib note "用户认为开会超过半小时就是浪费" --judgment` |
| 摘自用户自己写的文件 | `--extracted 文件` | `brainlib note "年度目标是跑完半马" --extracted plans/2026.md` |
| 你的推断，写上依据 | `--inferred` | `brainlib note "用户可能是夜猫子：三次都在晚上十点后发消息" --inferred` |
| 你的猜测 | `--guess` | 尽量不记 |
| 外部资料 | `--external 来源` | `brainlib note "绿茶的咖啡因比咖啡少" --external "某网站文章"` |

要点：

1. 原话就照原话记，不改写，不总结。
2. 一次记一件事，一两句话就够。
3. 加 `--category` 说明这件事属于哪一类。用户自己的偏好、习惯、价值观写 `--category 关于我`，会进 `me.md`；
   用户定下的事写 `--category 决定`，会进 `decisions.md`；发生过或打算做的事（出差、活动、今天过得怎样）写
   `--category 日记`，只进当天的日志。也可以写库里的文件夹名，比如 `--category 工作`。不写也行，brainlib 会按内容找最像的笔记。
   用户点名了哪篇，就加 `--target <那篇> --now`：brainlib 当场生成带来源标记的修改建议，拿给用户看，他同意就 `apply`。
4. 对用户很要紧的事加 `--importance 重要`；顺口一提、但值得留的加 `--importance 次要`，这类只进日志。
   不写就是「一般」，分类是「决定」的默认算重要。
5. 说话时间默认是记下的那一刻。补记以前说的话时加 `--said-at "2026-01-31 21:05"`，只记得日期就只写日期。
6. 用户改了主意（以前说不喝咖啡，现在说每天一杯），记新说法时加 `--replaces "不喝咖啡"`，写旧说法里的几个词就行。
   整理时会生成一条替换建议，旧说法留在新行末尾的括号里。用户把老偏好再说一遍时照常记，笔记不会重复，日志里会记下这次的时间。
7. 用户在第 6 题勾过敏感话题时，涉及这些话题的记录加 `--private`。
   是哪些话题，设置做完以后 `brainlib next` 每次都会列出来。
   用户选了敏感内容不进库，或者保险箱没设好，`--private` 的记录会被拒绝，这时告诉用户原因，不要换个办法记。
   `--privacy 机密` 的记录只进加密保险箱，没有保险箱就不存；`--privacy 绝密` 一律不存。
8. 密码、密钥、银行卡号一律不记，brainlib 也会拒绝（退出码 3）。建议用户放进密码管理器，笔记里最多留一句“在哪里能找到”。
9. 用户说的话一律用 `note` 记，这样来源标记才在。`brainlib propose` 只用来改正或删掉笔记里已有的内容，
   不用来加用户刚说的话，brainlib 拒绝保存的东西也不能用它写进去。拿不准算不算敏感，就问用户。
10. 对话快结束时，把这次用户定下的事和说过的偏好里还没记的，一件一条记下来。闲聊不记。

记录只进收件箱，不改任何笔记。之后 `brainlib classify` 会把它们变成修改建议（见 `skills/brainlib-organize/SKILL.md`），
同时按说话时间写进当天的日志。加了 `--now` 的记录例外，它当场就变成修改建议。

## 用库回答问题

用户问到和他有关的事（偏好、计划、以前的决定）时，先查再答：

1. `brainlib find "关键词"`
2. `brainlib read <路径>`，读最相关的一两篇。
3. `find` 的结果末尾如果有 `NOTED, NOT FILED YET`，那是之前的对话里记下、还没整理进笔记的内容，一样可以用，但要照它的来源标记说：
   `[said …]` 是用户的原话，`[inferred]`、`[guess]` 只是助手的推测，不能当成用户的意思。
4. 每条记录开头都有说话时间。同一件事有新旧两种说法时，以最新的为准。`brainlib index` 的「可能过时」一节会列出这种情况。
5. 想按条件看记录，用 `brainlib index --category 决定 --since 2026-10-01 --sort importance`；想看某天说了什么，用 `brainlib log --day 2026-10-20`。
6. 回答时说出处，比如“你在 me.md 里写过……”或“你 10 月 20 日跟我说过……”。库里没有就直说没有，不要编。
