# 了解用户：10 道选择题

## 怎么问

1. 一次只问一道。用 `brainlib next`（或 `brainlib onboard next`）给出的原题和选项，用用户选的语言念出来。
2. 不替用户回答，也不要猜。用户没想好可以跳过：`brainlib onboard answer Q2 skip`。
3. 标了 `(recommended)` 的是推荐项，可以告诉用户，但要让用户自己选。
4. 用户问为什么要问这个，就念 `IF THEY ASK WHY:` 那一行。
5. 记录答案：单选 `brainlib onboard answer Q4 c`；多选 `brainlib onboard answer Q1 a,c`。
6. 用户选“其他”时，把他的原话一起记下：`brainlib onboard answer Q1 f --other "用户的原话"`。
7. 10 道问完，把 `SAY TO USER:` 的结束语告诉用户。

## 10 道题在问什么

| 题 | 问什么 | 影响什么 |
|---|---|---|
| Q1 | 主要用来做什么 | 打开哪些功能 |
| Q2 | 涉及生活的哪些方面 | 东西怎么放，哪些方面要更注意隐私 |
| Q3 | 已有的笔记在哪里 | 用 init 还是 adopt，要不要先导出 |
| Q4 | 能改笔记到什么程度 | 最重要的权限：只读 / 只记收件箱 / 先提建议 / 小改直接做 / 大部分直接做 |
| Q5 | 记哪些东西 | 只记明确让记的 / 重要的话 / 再加你的观察 / 再加外部资料 |
| Q6 | 哪些话题敏感 | 这些默认按私密处理 |
| Q7 | 敏感内容怎么处理 | 不进库 / 加密保险箱 / 先问再读 / 不特别处理 |
| Q8 | 多久看一次整理建议 | 提醒审阅的节奏 |
| Q9 | 需要拿主意时怎么问 | 少问 / 选择题 / 不确定就问 / 先说猜测 |
| Q10 | 谁会用这个库 | 一个助手 / 多个助手 / 家人或同事 |

## 答案会变，不要定死

- 每道题都有复查日期：权限和隐私类大约 3 个月，其余大约半年。到期后 `brainlib next` 会让你再确认一次，先简单说明“好久没确认了，看看还是不是这样”。
- 用户的话和之前的选择对不上时，记一条信号。比如他选了“先提建议”，却说“这种小事你直接改就行”：
  `brainlib onboard signal Q4 "这种小事你直接改就行"`。同一道题累计 3 条，`brainlib next` 会让你重新问。
- 用户明确说要改，直接记新答案，比如 `brainlib onboard answer Q4 d`。旧答案会留在历史里。
- 看当前的答案和它们的实际效果：`brainlib onboard summary`。

## 例子

```text
你：开始之前，我想问你最多 10 个简单的选择题……第 4 题：我可以在多大程度上改你的笔记？
    a) 只读  b) 只记在收件箱里  c) 提出修改建议，你说可以了再改（推荐）  d) 小的补充直接加  e) 大部分直接做，事后告诉你
用户：c 吧
你（运行）：brainlib onboard answer Q4 c
```
