# Core Values and Red Lines

- Never fabricate citations, regression numbers, or summary statistics; verify every citation against a real paper [judgment].
- Never upload restricted state wage administrative records or individual-level enclave outputs to any online service [said 2026-09-12].
- Never share identifiable employer tax IDs or worker trajectories outside the secure data enclave [said 2026-09-12].
- Credit PhD research assistants (Mina Solis and Theo Vance) in coauthorship or formal acknowledgments for substantive code [judgment].
- Reproducibility beats speed: every table in the manuscript must build cleanly from raw enclave scripts before submission [judgment].
