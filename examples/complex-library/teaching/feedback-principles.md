# PhD Student Draft Feedback Principles

- Summarize the paper's core identification claim in one sentence at the top of the memo so the student sees how a reader interprets it [judgment].
- Never rewrite a student's R or Python estimation code directly; flag the econometric bug and let them implement the fix [said 2026-09-25].
- Limit each round of manuscript comments to three high-leverage structural issues before line-editing prose [judgment].
- Require advisees to include a README and master build script whenever they hand over a new draft of their second-year paper [said 2026-10-04].
- PhD students who get stuck on event-study plots usually have an unnormalized reference period or unbalanced cohort window [inferred].
