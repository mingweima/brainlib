# Writing Style Guide

- Prefer concrete sensory nouns and active verbs over abstract academic phrasing [judgment].
- Keep sentences under 25 words when writing lab safety instructions for tenth graders [said 2026-09-20].
- Explain Latin biology terms with their literal root meanings on first use [external: plain-science-writing].
- Avoid exclamation marks in parent emails; use a calm, encouraging tone instead [said 2026-10-08].
- Bakery chalkboard blurbs should be one punchy line mentioning the local grain or fruit used [inferred].
