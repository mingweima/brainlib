# About this library

This folder is my personal knowledge library. AI agents read it through brainlib.

- [About me](me.md): who I am and what matters to me. The most important page.
- `journal/`: the daily log, one file per day, named like `2026-01-31.md`. Everything an agent notes goes into the day's log in the order it was said.
- `decisions.md`: what I decided, one line each (created when first needed).
- `private/`: sensitive notes. Agents never see these.
- `_archive/`: old material kept for reference.
- `inbox-unsorted.md`: things not sorted yet (created when needed).

Anything else can go in its own note anywhere in this folder.
