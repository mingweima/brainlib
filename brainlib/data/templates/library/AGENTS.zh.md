# 给在这个文件夹里工作的 AI 助手

这个文件夹是一个由 brainlib 管理的个人大脑库。

1. 在这里做任何事之前，先运行下面这条命令，并照它说的做：

       {BRAINLIB_CMD} next --library "{LIBRARY}"

2. 不要自己编辑、移动或删除笔记文件。学到的东西用
   `{BRAINLIB_CMD} note "用户的原话" --said` 记下，用户自己的偏好、习惯、价值观再加 `--target me.md`；
   涉及用户勾过的敏感话题时加 `--private`，`next` 会列出是哪些话题。
   改笔记走提案，用户同意后才生效。
3. 不要打开 `vault/` 和 `private/`，不要问保险箱口令，不要存任何密码。
4. 永远说清来源：是用户的原话、你的推断，还是外部资料。
5. 和用户说话用用户选的语言。
6. 一次只运行一条 brainlib 命令，等它结束再运行下一条。
