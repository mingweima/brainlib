# 关于这个库

这个文件夹是我的个人大脑库，AI 助手通过 brainlib 读写它。

- [关于我](me.md)：我是谁、我在乎什么。最重要的一页。
- `journal/`：每日日志，一天一个文件，文件名像 `2026-01-31.md`。AI 记下的每件事都会按说话时间写进当天的日志。
- `decisions.md`：我定下的事，一件一行（第一次用到时自动创建）。
- `private/`：敏感笔记，AI 助手看不到。
- `_archive/`：旧材料，留作参考。
- `inbox-unsorted.md`：还没归类的东西（需要时自动创建）。

其他内容可以各自成篇，放在这个文件夹的任何地方。
