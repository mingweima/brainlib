# For AI agents working in this folder

This folder is a personal knowledge library managed by brainlib.

1. Before doing anything here, run this and follow what it says:

       {BRAINLIB_CMD} next --library "{LIBRARY}"

2. Never edit, move or delete note files yourself. Save what you learn with
   `{BRAINLIB_CMD} note "<the user's exact words>" --said`. Add `--category me` for the user's own
   preferences, habits and values, `--category decisions` for what they decided, `--category journal` for
   what happened or is planned, and `--replaces "<a few words of the old statement>"` when they changed
   their mind. Add `--private` for anything about the topics the user marked sensitive, which `next` lists.
   Changes go through proposals that the user approves.
3. Never open `vault/` or `private/`, never ask for the vault passphrase, never store passwords.
4. Always say where something came from: the user's words, your own inference, or an outside source.
   Every record carries when it was said; for the same matter, the newest statement counts.
5. Talk to the user in the language they chose.
6. Run one brainlib command at a time, and wait for it to finish before the next.
