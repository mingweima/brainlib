# 路线图 / Roadmap

一步一步来。先把核心做扎实，即任何 AI 都能接手、先读再答、记下来源、你批了才改、跟着你变。
加密和出口门禁这类技术上复杂的「硬的一层」，v0.1 只带了最简单的一版，更强的做法放在后面。

## v0.2 记录和分层索引（已发布）

每条记录带说话时间、分类、重要性、私密等级；记录分 L0 到 L3，索引长度固定；每日日志；同一件事以最新的说法为准。见 [records.md](records.md)。

## v0.2.x 核心打磨

- 普通用户和小模型实际用下来卡住的地方，逐个改掉。
- 在 Windows 上实际装起来用一遍。
- 隐私加强，来自 v0.1.5 的沙盒测试。漏加 `--private` 时能补救，能删掉缓存区里的一条；认出更多密钥格式（没有「是」或冒号的密码、`sk_test_` 这类前缀、没有前缀的高熵串）；`find` 先遮蔽再匹配；体检也提示笔记里的卡号和手机号。
- 更好的中文归类和查找。可选接本地小模型（`classifier.backend = command`），规则后端加中文分词和同义词。
- 开场题里加一两道了解用户本人的题（怎么称呼、做什么、喜欢怎样沟通），装完 `me.md` 不再是空模板。
- 通过提案移动、重命名、归档文件。
- 常见应用的导入向导，先做 Notion、Apple 备忘录、印象笔记的导出文件。
- 把 `brainlib` 加进系统 PATH 的一键命令。
- 英文版技能说明。

## v0.3 更懂你

- 校准。先猜再问，记下猜中率，帮用户看出哪个助手更懂自己。
- 定期回顾，按用户设定的节奏生成周报。
- 多助手角色，每个助手只看到它需要的部分，按区域和层级裁剪。

## 以后，隐私的硬的一层

现在的保险箱靠你自己输的口令，发布前的扫描靠你自己的私密词表。下面这些更硬，但技术上也更复杂，等核心稳定以后再做。

- 保险箱的钥匙放在要本人在场才能用的地方，比如系统钥匙串加指纹、硬件安全钥匙、密码管理器解锁。AI 就算读到文件，拿到的也只是密文。
- 给 AI 有时限的摘录授权。你同意以后，它只能在一段时间里看到你选的那几段。
- 密码和密钥在库里只放「去哪里取」，用的时候由密码管理器直接交给命令，不经过 AI。
- 出口门禁。AI 要把库里的内容发到网上、发邮件或交给别的服务之前，先过一道检查，碰到私密内容就拦下。
- 保险箱里的文件名也加密。

## 一直坚持的 / Always

- 笔记是普通 Markdown，归用户所有，随时可以带走。
- 向下兼容。只增不改，不自动改写用户文件。
- 隐私优先。拿不准时不记、不发。
